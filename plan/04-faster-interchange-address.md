# 4. Faster interchange of address chunks (§4)

Part of the [plan](../PLAN.md). See [COMPONENTS.md](../COMPONENTS.md) for what each file proves.

## How the proof goes

The section gives a fast tape algorithm for interchanging (transposing) address chunks. The linear-algebra lemmas turn the transpose of digit coordinates into a short product of shears, each realized by a fixed affine network over a small prime field. A recursive algorithm then handles power widths: each node splits rows into roles, applies the shears, recurses on children of smaller logical volume and merges back, with all control on a fixed number of tapes. Padding and a piece decomposition extend this to every width, and a binary wrapper gives the final theorem.

1. Recurrence. `Recurrence` proves that the per-level costs satisfy F(k) <= K (m^k)^tau once s/W <= m^tau, and bounds digit pieces and the padding overheads used later.
2. Factorization (Lemmas 4.1 and 4.2). `LowerTriangular` and `PivotRank` give A = E1 Pi E2 with lower-triangular factors and a partial permutation of rank A ones; `Shear` and `Modular` turn the resulting shear into fixed certified coefficients and affine instructions with an exact interchange count.
3. Tape building blocks. Cyclic row split and merge, counted stacks, variable-length binary descriptor stacks, descriptor division and a finite return dispatcher are proved with exact endpoints and linear costs.
4. Base case. The width-one digit interchange runs on the permanent bank and is selected by a physical width guard (`RecursiveDigitInterchangeClean`, `RecursiveDigitRoleBank`).
5. Node work and call protocol. At each recursive node the machine splits rows into roles, applies shifts, scalings and coordinate views, computes child headers by descriptor division, pushes the parent frame, calls the child and restores the parent; every cost is charged to the child's logical volume (`RecursiveInterchangeVolume`, `RecursiveChildPrepare`, `RecursiveCallProtocol`).
6. Power-width interchange (Proposition 4.3). The fixed Shared50 cyclic machine binds these blocks into one program; `Shared50RecursiveInduction` proves terminating child calls and correctness, and `Shared50RecursiveRootExecution` gives the root run within the certified budget.
7. Arbitrary widths (Lemma 4.4). Row and range padding reduce general shapes, and a runtime piece dispatcher splits the width into power pieces, runs recursive slice calls and a high-width exchange or elementary fallback; `ArbitraryWidthOriginalTotalRun` covers every radix width including zero.
8. Binary interchange. Binary-to-radix preparation and equal- or adjacent-width cases are joined by a physical three-way selector; `BinaryInterchangeRun` and `BinaryInterchangeBudget` give the exact rectangular transpose with exponent 1 - 296/10^11.
