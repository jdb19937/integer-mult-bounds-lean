# Selected T16 finite charge checkpoint

`scripts/generate_t16_certificate.py SOURCE_CHECKOUT` deterministically imports
hash-pinned projections from the selected T16 plan, its 69,120 owner records,
and the matching R480 native word and event lists. It executes no supplier code.
Exact paths and file hashes are recorded in `provenance.json`; each orientation
module also records its canonical event-list hash.

The matching native artifacts are retained under
`research/r480-owner-optimum/inputs/local`. The older local evidence inside
`complex-t16-rare-pattern-exchanges/upstream1087.tar.gz` is R492 and must not be
substituted. The local Clifford review has different receipt bytes, but its
upstream timing/reference-normalized digest matches the selected plan.

## Kernel claims

- `Forward` and `Backward` retain the literal index, kind, register, frame IDs,
  frame dimensions and rank of all 3,494 charged events in each orientation.
  Every chunk checks index/frame/dimension bounds and the numerical rank jump.
  The histogram is computed from those events, not merely asserted from the
  selected profile: 2,412 rank-one, 418 rank-two, 432 rank-three, 142 rank-four,
  82 rank-five and eight rank-eight children per call.
- `Schedule.scheduleCost_eq` derives the sum of arbitrary natural-number
  rank prices along the literal 144-call schedule. Each call checks stage,
  replica and orientation consistency. Both orientations have the same
  certified charge profile.
- `Owners0` through `Owners3` retain every owner record's time, stage, replica,
  helper, owner replica, child, port, copy, family, offset and width. The checks
  establish bounds, the copy identity, positive bounded width and ambient
  slice capacity. `Owners` combines their validity and 69,120-row count.
- `selected_profile_cost` states the exact weighted arithmetic after adding
  the nominated idle inventory. Its idle term is explicit; the theorem does
  not assert that the actual hosting realizes that inventory.

## Boundaries

The importer and hashes bind external data by provenance; Lean checks the
generated literals. Frame dimensions are projected from the pinned canonical
frame table, but frame linear independence, label-state continuity and scalar
semantics are not proved here. Neither are call permutation/completeness,
owner-call alignment, family identity, per-call owner uniqueness, bridge-aware
idle windows, disjoint occupied slices, exact prefix occupancy, residual
inventory realization, dirty-input restoration, Clifford identities, precision,
compiler costs, all-size transfer or the selected saving. The 144-call weighted
charge theorem becomes a supplier cost bound only after those execution and
hosting obligations are connected.

The source's 193 move records describe changed placements. Against the archived
baseline, 27 further owner rows change only their offset, so the full owner JSON
diff contains 220 rows. This checkpoint imports the complete final owner data.

All checks use the repository's guarded checker and default proof limits.
