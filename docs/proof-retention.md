# Proof retention and remaining purge candidates

The completed Mathlib proof is the primary route. The native CompactComplex
controller has now been retired; see the [retirement record](retired-compact-complex.md)
and [exact removed-file manifest](retired-compact-complex.json).

## Retained and removed code

| Set | Lean modules | Source lines |
| --- | ---: | ---: |
| Completed theorem's transitive imports | 1,989 | 532,699 |
| Additional public compatibility and integration modules | 26 | 4,984 |
| Additional dependencies of legacy focused audits | 242 | 59,104 |
| Retired controller and unused dependent wrappers | 635 | 109,973 |
| Retired actual-multiplier stage wrappers | 16 | 1,317 |
| Remaining conservative removal candidates | 864 | 87,638 |

The proof closure still includes 895 modules in the `Machine` namespace,
696 network/certificate modules, 63 Schoenhage–Strassen modules and 241 Mathlib
host-proof modules. Its imports and source-line totals are unchanged by the
retirement. Two similarly named modules remain necessary:
`CompactComplexActualCallFrameEdge` and `CompactComplexActualCallLoweredNetwork`.
Whole directories or a broad `CompactComplex*` glob must not be removed.

The authoritative current lists are in [proof-retention.json](proof-retention.json),
regenerated by [proof-retention.py](../scripts/proof-retention.py). They protect
the theorem, public compatibility facade and focused checks.

The follow-up [actual-stage retirement](retired-compact-actual.md) removed
16 more unused wrappers without changing any protected import closure.

## Remaining candidates

`conservative_candidate_files` lists 864 remaining files outside the completed
proof, public interfaces and legacy focused audits. Another 242 modules remain
because the chirp, adapter and recovery audits depend on them; they are listed
in `retain_for_legacy_audits`. Retiring those checks together would increase
the candidate set to 1,106 modules and 146,742 lines.

**A subset of the candidate list need not be removable alone.** Surviving
legacy modules may import it even though the final theorem does not. Every
removal batch must include its unused transitive importers, or otherwise
resolve those imports, and must exclude protected modules. This is why the
426 controller candidates were retired with 209 dependent wrappers.

The import closure is conservative: declarations inside retained modules may
be unused, but that requires a separate declaration-level or import-minimization
audit. Candidates can also retain value for the stronger `83/10^12` target;
Git preserves the retired development.

## Proof-integrity checks

`CompletedProofCheck.lean` imports the final theorem directly, independently
of the all-components root, and audits every imported project declaration for
only `propext`, `Classical.choice` and `Quot.sound`. It is included in CI.
The main `AxiomAudit.lean` continues to audit every declaration imported by the
surviving library root; all other focused audit files are retained.

Reproduce the current inventory and checks with:

```sh
python3 -m unittest discover -s scripts -p test_proof_retention.py
python3 scripts/proof-retention.py --manifest docs/proof-retention.json --check
python3 scripts/check-lean-safe.py CompletedProofCheck.lean
```

Omit `--check` to refresh the manifest. The audit script never deletes Lean
files. A deletion must also prune `IntegerMultBounds.lean`, update retired
component documentation, regenerate plan status and pass the guarded build
and all retained audits.
